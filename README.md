# 🤖 Telegram Бот — Трезвый водитель Дубай

Простой Telegram-бот для службы "Трезвый водитель Дубай". Позволяет клиентам отправить геолокацию, связаться через WhatsApp или позвонить.

## 📦 Установка

1. Склонируй репозиторий или загрузи файл `bot.py`
2. Установи зависимости:
```
pip install -r requirements.txt
```

3. Запусти бота:
```
python bot.py
```

## ⚙️ Возможности
- Мультиязычный интерфейс (русский / английский)
- Кнопки: отправка геолокации, WhatsApp, звонок
- Автоматическая отправка геолокации администратору
- Команды: `/start`, `/order`, `/help`, `/info`, `/contact`
